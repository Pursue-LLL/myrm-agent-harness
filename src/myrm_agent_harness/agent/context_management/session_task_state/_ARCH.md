# session_task_state 模块架构

## 架构概述

会话任务状态机与免压缩 Task HUD 注入引擎。
将任务清单与执行阶段提升为独立于对话历史的一等公民数据结构，彻底解决长轮次上下文压缩导致任务清单被稀释丢失、目标漂移的顽疾。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `state_machine.py` | 核心 | `SessionTaskState` 与 `TaskItem` 状态机，支持任务增删改查、进度统计与抗压缩 HUD 注入文本格式化 | ✅ |
| `__init__.py` | 入口 | 模块门面与公共类型导出 | ✅ |

## 契约要点

- **状态隔离**：任务状态独立持久化，不随 LLM 历史消息一起进入有损上下文蒸馏/压缩通道；
- **不可降解 HUD 注入**：无论历史消息如何被总结裁剪，每次构建系统 Prompt 时均从 `SessionTaskState` 提取最新坐标系；
- **单文件代码质量红线**：单文件行数严格低于 400 行，零 `Any`。
