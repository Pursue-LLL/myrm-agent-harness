# hierarchical_supply

Architecture and module inventory for the `hierarchical_supply` package.

## Modules

| File | Description |
| --- | --- |
| `__init__.py` | Package entry point exporting hierarchical supply types, builder, folding sentry, and facade suite |
| `hierarchical_supply_types.py` | Domain models and contracts for L1-L3 context tiers, progressive expansion, and folding budgets |
| `hierarchical_context_tree_builder.py` | Builder compiling multi-tiered enterprise context into an indexed HierarchyTree with parent-child links |
| `adaptive_branch_folding_sentry.py` | Adaptive branch folding sentry managing active L3 detail ceilings and collapsing completed branches |
| `hierarchical_progressive_disclosure_suite.py` | End-to-end facade orchestrating hierarchical enterprise context abstraction and progressive disclosure supply |
