# Sandbox Hardware Telemetry & Runaway Circuit Breaker Module Architecture

## 概述
多维度沙箱硬件资源动态遥测与三级阶梯式失控死循环自动熔断器套件：
- 采集 CPU、内存 (RSS/总量)、磁盘 Volume 占用与网络出入流量；
- 三级阶梯熔断保护（Level 1 预警 80% ➔ Level 2 挂起 90% ➔ Level 3 硬熔断 95% 或配额耗尽）；
- 线程安全状态机与违规事故流历史留痕；
- 避免智能体长任务死循环拖死宿主机硬件或消耗枯竭沙箱算力。

## 文件列表

| 文件名 | 类型 | 职责说明 | 状态 |
| :--- | :--- | :--- | :--- |
| `models.py` | 实体 | 硬件度量样本、三级阶梯安全级别、熔断器配置与事故评估不可变数据结构 | ✅ |
| `circuit_breaker.py` | 核心引擎 | 线程安全三级阶梯熔断状态机、连续违规计数、动态限额阈值与全局单例 | ✅ |
| `__init__.py` | 门面 | 聚合导出模块内所有模型与单例获取函数 | ✅ |
