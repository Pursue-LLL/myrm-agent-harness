# observability/deployment_funnel/

## 架构概述

部署漏斗监控与反馈提醒回路套件。
针对交付物部署上线后的真实运行态势，提供 4 阶梯用户转化漏斗埋点追踪（VIEW ➔ ENGAGE ➔ ACTION ➔ COMPLETE）、断点热点流失率统计、用户情感反馈聚合与自动触发 Nudge 提醒，并支持将高阶改进目标抛回给 Agent 执行自主闭环。

上级文档：[../_ARCH.md](../_ARCH.md)。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `__init__.py` | 门面 | 聚合导出部署漏斗阶段枚举、数据记录与引擎 | ✅ |
| `models.py` | 模型 | 漏斗阶段、用户事件记录、用户反馈与漏斗快照不可变数据模型定义 | ✅ |
| `funnel_engine.py` | 核心 | 线程安全漏斗事件收集、流失率计算、Nudge 告警检测与自主改进目标生成引擎 | ✅ |
