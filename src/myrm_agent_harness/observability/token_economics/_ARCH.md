# myrm_agent_harness/observability/token_economics/

## 架构概述

长任务 Token 经济学透明透视、99% 缓存节流真实收益与算力账单防刺客引擎。上级文档：[../_ARCH.md](../_ARCH.md)。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `models.py` | 模型 | Token 经济学快照、缓存节省回报指标、单位成本基线、漂移告警与熔断策略类型 | ✅ |
| `calculator.py` | 引擎 | 多模型 Prompt 缓存成本、无缓存基准对比、净节省金额与 ROI 换算计算器 | ✅ |
| `drift_detector.py` | 探针 | 基于滑动历史窗口的单位成本漂移探针，检测 >20% 成本偏离并执行透明归因 | ✅ |
| `guard.py` | 风控 | 算力账单防刺客护卫与软硬双阶梯熔断刹车，防止死循环导致账单失控 | ✅ |
| `__init__.py` | 门面 | 聚合导出 Token 经济学与缓存防刺客套件全部核心组件与契约 | ✅ |
