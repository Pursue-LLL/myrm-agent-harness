# Event Causality Lineage & Action Attribution Module Architecture

## 概述
事件驱动全链路因果溯源时间线、动作归因图谱与审计白盒透视套件：
- 消除 7×24 小时自主运行下对“幽灵文件变更”的恐惧；
- 将外部事件 (GitHub/Slack/MCP/Cron) 与规则匹配、智能体决策、工具动作与最终代码产出形成完整有向因果链；
- 维护倒排文件归因索引，实现 1 秒内按文件反向追溯诱发事件与理由；
- 提供企业级审计白盒透明度与全链路责权归属。

## 文件列表

| 文件名 | 类型 | 职责说明 | 状态 |
| :--- | :--- | :--- | :--- |
| `models.py` | 实体 | 外部触发事件、规则匹配、智能体动作节点、产物变更、因果链 DAG 与反向追溯结果不可变模型 | ✅ |
| `tracker.py` | 引擎 | 线程安全因果链条注册表、倒排文件归因索引、正向 DAG 检索与反向 1 秒追溯引擎 | ✅ |
| `__init__.py` | 门面 | 聚合导出模块内所有模型与单例获取函数 | ✅ |
