# cumulative_delivery_budget/

## 架构概述

多智能体整轮交付全生命周期成本核算、未知用量审计账本与硬预算熔断管理包。遵循太一企业版 Team Runtime 双账本设计哲学：
1. **二元双账本**：`Trial Ledger` 记录单次 Worker 尝试细颗粒度开销，`Cumulative Delivery Ledger` 聚合需求全周期累计支出；
2. **显式未知用量审计**：针对网络中断、无 Usage 回包等黑盒异常，严禁记为 0，显式打标并进行保守参数计提；
3. **多级硬预算门禁**：支持 70% 软预警与 100% 硬熔断挂起（Circuit Breaker），防止失控跑飞烧钱。
