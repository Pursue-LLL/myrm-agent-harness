# bilibili/tools/

## Overview

Self-contained executable tools for Bilibili domain harvesting.

## Tools

| File | Role | Description | I/O/P |
|------|------|-------------|-------|
| `export_data.py` | Tool | Export extracted Bilibili data to Excel (.xlsx) or CSV | ✅ |
| `get_video_comments.py` | Tool | Extract comments from current Bilibili video page | ✅ |
| `get_video_feed.py` | Tool | Extract structured video cards with bvid, title, play count, and duration | ✅ |
