# zk_vault_watermark/

## 架构概述

零知识端到端记忆保险箱、防非法克隆与上下文导出数字隐形水印主权治理套件（Item 159）。
深度解决 Agent 私域长效记忆在持久化与外部共享中明文裸奔、缺乏硬件租户绑定、可被无门槛物理复制盗用、导出数据无法溯源的资产安全漏洞。

## 文件清单

| 文件 | 地位 | 职责 | I/O/P |
|------|------|------|-------|
| `__init__.py` | 门面 | 模块公共符号统一导出 | ✅ |
| `models.py` | 契约 | 信封加密容器、数字水印、沙箱绑定指纹、脱敏资产模型 | ✅ |
| `envelope_crypto.py` | 核心 | 本地主密钥 KEK 派生与瞬时 DEK 信封加解密引擎 | ✅ |
| `watermark_engine.py` | 核心 | 抗篡改不可见零宽频域数字水印注入器与溯源提取器 | ✅ |
| `distillation_exporter.py` | 核心 | 三级敏感度分级过滤与知识脱敏蒸馏导出器 | ✅ |
| `anti_cloning_gate.py` | 核心 | 沙箱物理环境与租户强绑定防克隆门禁 | ✅ |
| `zk_vault_manager.py` | 门面 | 协调存储封印、解密、脱敏导出与沙箱鉴权的主控中枢 | ✅ |
