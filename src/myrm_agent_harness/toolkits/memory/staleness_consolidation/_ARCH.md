# staleness_consolidation/

## 架构概述

自动记忆陈旧衰减探测、过期偏好安全驱逐与定期记忆盘点重塑套件（Item 158）。
基于时间半衰期与召回热度衰减模型、代码库事实反向断言核查器、以及零碎记忆语义聚类重塑合并引擎，彻底打破“记忆只增不减、过时前提持续毒化输出”的系统隐患。
